# ИИ-советник и чеки по фото

Экран **Настройки → ИИ-советник** (и кнопка «Спросить ИИ про этот отчёт» в отчётах)
отправляет выбранные вами данные модели и возвращает разбор простым текстом.
Тот же провайдер читает **фото чеков**, если модель умеет работать с картинками.

## Провайдеры

Все вызовы — прямой HTTP из общего кода (`net/Ai.kt`, Ktor), одинаково на Android и iOS.

| Провайдер | Запрос | Модель по умолчанию | Фото чеков | Ключ |
| --- | --- | --- | --- | --- |
| Claude | `POST api.anthropic.com/v1/messages` | `claude-opus-5` | да | `sk-ant-…` |
| OpenAI | `POST api.openai.com/v1/chat/completions` | `gpt-5-mini` | да | `sk-…` |
| Gemini | `models/{model}:generateContent` | `gemini-2.5-flash` | да | `AIza…` |
| GigaChat | токен `ngw.devices.sberbank.ru:9443/api/v2/oauth`, затем `gigachat.devices.sberbank.ru/api/v1/chat/completions` | `GigaChat-2` | нет | Authorization key |
| YandexGPT | `POST llm.api.cloud.yandex.net/foundationModels/v1/completion` | `yandexgpt-lite` | нет | API-ключ сервисного аккаунта + каталог |
| Свой endpoint | OpenAI-совместимый `/chat/completions` | задаётся вручную | зависит от модели | необязателен |

Модель меняется в поле «Модель». Для Claude включён серверный откат (`fallbacks`):
если модель откажется отвечать, запрос уйдёт другой модели Anthropic.

**GigaChat.** В поле ключа — «Authorization key» из личного кабинета
[developers.sber.ru](https://developers.sber.ru) (GigaChat API для физлиц, область
`GIGACHAT_API_PERS`). Приложение само меняет его на токен доступа и держит токен в памяти
до истечения. Сервер Сбера подписан **корневым сертификатом Минцифры России**, которому
телефоны по умолчанию не доверяют: его нужно установить с [gu-st.ru](https://www.gosuslugi.ru/crt)
(Android: Настройки → Безопасность → Установка сертификата; iPhone: установить профиль
и включить полное доверие). На Android приложение доверяет таким сертификатам только
для доменов Сбера — см. `app/src/main/res/xml/network_security_config.xml`.
Без сертификата приложение так и скажет, а не «нет связи».

**YandexGPT.** Нужны API-ключ сервисного аккаунта с ролью `ai.languageModels.user`
и **идентификатор каталога** (folder ID) — отдельное поле на экране советника.
Модель задаётся коротко (`yandexgpt-lite`, `yandexgpt`, `yandexgpt/rc`) или полным
URI `gpt://<каталог>/<модель>/latest`.

**Свой endpoint** — базовый адрес, например `http://192.168.1.10:11434/v1` для локальной
модели в домашней сети (для этого разрешён нешифрованный трафик).

## Ключи

Ключ вводится в приложении и хранится в защищённом хранилище телефона: Android Keystore
(AES-GCM, `data/SecureStore.kt`) или iOS Keychain. Он не попадает ни в файл данных,
ни в резервную копию, ни в общий бюджет, ни в логи. У каждого провайдера свой ключ.

**Без ключа** приложение отвечает офлайн-разбором: главная статья расходов, превышенные
лимиты, сколько освободится при сокращении на 15% — посчитано локально, без сети.

## Что уходит в запрос

**Вопрос советнику** — ровно то, что отмечено галочками:

- **Операции** — за выбранный в отчётах период, до 80 штук: дата, название, категория, сумма;
- **Бюджеты** — лимиты месяца и потраченное;
- **Счета и валюты** — названия, балансы, основная валюта;
- **Цели** — название, накоплено, цель;
- **Текущий отчёт** — разрез с процентами и сравнение с прошлым периодом.

Под галочками показано, сколько строк и примерно сколько токенов уйдёт. Ответ просим
на языке интерфейса, простым текстом без разметки.

**Фото чека** — сам снимок, список ваших категорий расходов, основная валюта и сегодняшняя
дата. Модель возвращает строгий JSON (магазин, дата, валюта, сумма, позиции, категория),
который превращается в черновик на экране «На проверку». Если модель выбранного
провайдера картинки не читает, кнопка «Фото чека» не показывается — остаётся QR-код,
которому ни ИИ, ни интернет не нужны.

## Ошибки

Ответ с ошибкой не теряется: приложение показывает понятное сообщение (неверный ключ,
лимит запросов, модель не найдена, нет связи, не установлен сертификат для GigaChat,
не указан каталог YandexGPT) и **дополняет его офлайн-разбором**, чтобы экран не был пустым.
