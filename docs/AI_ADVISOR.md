# ИИ-советник

Экран **Настройки → ИИ-советник** (и кнопка «Спросить ИИ про этот отчёт» в отчётах)
отправляет выбранные вами данные модели и возвращает разбор простым текстом.

## Провайдеры

| Провайдер | Как вызывается | Модель по умолчанию |
| --- | --- | --- |
| Claude | официальный Java SDK Anthropic (`com.anthropic:anthropic-java`) | `claude-opus-5` |
| OpenAI | HTTP, `POST /v1/chat/completions` | `gpt-5-mini` |
| Gemini | HTTP, `models/{model}:generateContent` | `gemini-2.5-flash` |
| Свой endpoint | HTTP, OpenAI-совместимый `/chat/completions` | задаётся вручную |

Модель у каждого провайдера меняется в поле «Модель». Для своего endpoint указывается
базовый адрес, например `http://192.168.1.10:11434/v1` — так подключается локальная модель
в домашней сети (для этого в манифесте разрешён нешифрованный трафик).

Для Claude включён серверный откат (`fallbacks`): если модель откажется отвечать,
запрос автоматически уйдёт другой модели Anthropic.

## Ключи

Ключ вводится в приложении и шифруется AES-GCM ключом из **Android Keystore**
(`data/SecureStore.kt`). Он не попадает ни в файл данных, ни в резервную копию на Диске,
ни в логи. Каждый провайдер хранит свой ключ отдельно.

**Без ключа** приложение отвечает офлайн-разбором: те же выводы (главная статья расходов,
превышенные лимиты, сколько освободится при сокращении на 15%), посчитанные локально
по правилам, без сети.

## Что уходит в запрос

Ровно то, что отмечено галочками на экране советника:

- **Операции** — за выбранный в отчётах период, до 80 штук: дата, название, категория, сумма;
- **Бюджеты** — лимиты месяца и потраченное;
- **Счета и валюты** — названия, балансы, основная валюта;
- **Цели** — название, накоплено, цель;
- **Текущий отчёт** — разрез с процентами и сравнение с прошлым периодом.

Под галочками показано, сколько строк и примерно сколько токенов уйдёт в запрос.
Ни имя пользователя, ни ключи, ни номера карт (кроме того, что вы сами написали
в названии счёта) не отправляются.

## Ошибки

Ответ провайдера с ошибкой не теряется: приложение показывает понятное сообщение
(неверный ключ, лимит запросов, модель не найдена, нет связи) и **дополняет его
офлайн-разбором**, чтобы экран не оставался пустым.
